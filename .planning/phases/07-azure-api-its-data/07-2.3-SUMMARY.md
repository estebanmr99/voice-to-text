# Phase 7 Plan 2.3: AWS Transcribe Provider

AWS Transcribe provider that uploads audio to S3, starts async transcription jobs, polls for completion, and downloads transcripts.

## Key Files

### Created
- `src/cloud_providers/__init__.py` — cloud_providers package marker
- `src/cloud_providers/aws.py` — AWSTranscribeProvider implementation (374 lines)
- `tests/test_cloud_providers_aws.py` — 31 mocked unit tests

### Modified
- `src/cloud_transcriber.py` — added `register_provider()`, `get_provider_names()`, `_ensure_providers()` lazy registry, and AWS provider support in `CloudTranscriber.start()`

## Architecture

```
AWSTranscribeProvider(TranscriptionProvider)
  ├── _get_clients()         — lazy boto3.init (transcribe + S3)
  ├── transcribe()           — upload to S3 → start job → wait → download
  ├── _upload_to_s3()        — put_object to configured bucket
  ├── _wait_for_job()        — built-in waiter with polling fallback
  ├── _poll_until_complete() — get_transcription_job loop (30 min timeout)
  └── _download_transcript() — GET pre-signed TranscriptFileUri via urllib
```

## AWS API Flow

1. `s3.put_object(Bucket, Key, Body)` — upload audio bytes
2. `transcribe.start_transcription_job(TranscriptionJobName, Media, LanguageCode/IdentifyLanguage)` — start async job
3. `transcribe.get_waiter("transcription_job_completed").wait()` — built-in waiter with polling fallback
4. `GET {TranscriptFileUri}` — download transcript JSON from pre-signed S3 URL
5. Extract `results.transcripts[0].transcript` — return as `TranscriptionResult`

## Key Features

- **Lazy boto3**: AWS SDK imported only when first `.transcribe()` call — zero cost if not used
- **Boto3 credential chain**: No API keys in code — uses env vars, `~/.aws/credentials`, or IAM role
- **Language code mapping**: `es` → `es-US`, `en` → `en-US`, `None` → auto-detect (`IdentifyLanguage=True`)
- **Waiter + fallback polling**: Uses built-in waiter; if it fails, falls back to polling (5s interval, 30 min timeout)
- **S3 key naming**: `transcribe-input/{timestamp_ms}_{filename}` — unique per call
- **Job naming**: `spanglish-dictation-{timestamp_ms}` — unique per call
- **Media format detection**: Extracts from filename extension, falls back to `wav`
- **Error handling**: S3 upload failure, job start failure, job failure (with `FailureReason`), timeout, missing `TranscriptFileUri`

## Deviations from Plan

### [Rule 3] Created `cloud_transcriber.py` scaffolding and provider registry

Task 2.2 (`cloud_transcriber.py`) was expected to exist before Task 2.3, but the files didn't exist at the start of this task. Added `register_provider()`, `get_provider_names()`, `_ensure_providers()` lazy registry, and AWS provider registration to `cloud_transcriber.py` as prerequisite infrastructure.

### [Rule 1] Fixed circular import in provider registration

The initial implementation tried to register the AWS provider at module level in `cloud_transcriber.py`, causing a circular import (`cloud_transcriber` → `cloud_providers.aws` → `cloud_transcriber`). Fixed by making registration lazy via `_ensure_providers()` called on first access.
