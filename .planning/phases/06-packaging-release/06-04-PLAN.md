<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI build runner → GitHub release | CI-created files become public release assets. |
| release folder → verifier | Local artifacts are accepted or rejected before publication. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11 | Tampering | `SHA256SUMS.txt` | mitigate | `prepare_release.ps1` computes SHA-256 after artifact creation and verifier requires checksum file. |
| T-06-12 | Information Disclosure | GitHub release workflow | mitigate | Tests assert workflow does not download models or reference CUDA/cuDNN artifacts. |
| T-06-13 | Repudiation | release checklist | mitigate | Checklist requires SBOM, notices, checksums, privacy smoke command, and blocked-artifact confirmation. |
| T-06-14 | Denial of Service | CI dependency install | accept | Release workflow failure blocks publishing; no runtime impact. |
</threat_model>
