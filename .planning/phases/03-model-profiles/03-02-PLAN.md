    1. **HardwareInfo dataclass**:
       ```python
       @dataclass
       class HardwareInfo:
           cpu_name: str = ""
           cpu_logical_cores: int = 0
           has_nvidia_gpu: bool = False
           nvidia_gpu_name: str = ""
           vram_mb: int | None = None
       ```

    2. **CPU detection** (always runs):
       - `platform.processor()` → `cpu_name`
       - `os.cpu_count()` → `cpu_logical_cores`

    3. **NVIDIA detection** (advisory only, fail-safe):
       - **Primary method:** `subprocess.run(["wmic", "path", "win32_VideoController", "get", "Name"], capture_output=True, text=True, timeout=5)`
         - Parse output for case-insensitive match of `NVIDIA` or `GeForce` or `RTX` or `Quadro`
         - If matched → `has_nvidia_gpu = True`, `nvidia_gpu_name = matched line stripped`
       - **Secondary method (optional):** Try loading `nvml.dll` via `ctypes.windll.nvml` to query VRAM size. If DLL missing or any error → silently ignore, `vram_mb = None`.
         - Only attempt if primary method already found NVIDIA; this is for extra info, not for detection itself.
       - If `wmic` fails (subprocess error, timeout, non-zero exit) → `has_nvidia_gpu = False`, no exception raised.

    4. **Safety constraints**:
       - No user input reaches subprocess arguments (fixed command list)
       - `timeout=5` on subprocess to prevent hanging
       - All exceptions caught and logged; function never raises
       - No network calls (wmic is local WMI, nvml.dll is local driver)

    5. **Create `tests/test_hardware_detector.py`**:
       - `test_detect_hardware_returns_hardware_info` — mock `platform.processor` and `os.cpu_count`, assert result is HardwareInfo with expected CPU fields
       - `test_detect_hardware_no_nvidia` — mock `subprocess.run` to return non-NVIDIA GPU name, assert `has_nvidia_gpu is False`
       - `test_detect_hardware_has_nvidia` — mock `subprocess.run` to return "NVIDIA GeForce RTX 2070 Super", assert `has_nvidia_gpu is True` and correct name
       - `test_detect_hardware_wmic_failure` — mock `subprocess.run` to raise `CalledProcessError`, assert `has_nvidia_gpu is False` and no exception
       - `test_detect_hardware_wmic_timeout` — mock `subprocess.run` to raise `TimeoutExpired`, assert graceful fallback
       - `test_detect_hardware_nvml_vram` — mock successful nvml load and query, assert `vram_mb` populated (optional test, skip if nvml unavailable)

    1. **ProfileResolutionResult dataclass**:
       ```python
       @dataclass
       class ProfileResolutionResult:
           model_info: ModelInfo | None          # The selected valid model, or None
           profile_used: str                     # Canonical profile name that produced the model
           fallback_applied: bool                # True if preferred profile was unavailable and fallback used
           advisory_message: str = ""            # Human-readable guidance (e.g., "NVIDIA recommended but CPU used")
           error_message: str = ""               # Error if no valid model found
       ```

    2. **Implement `resolve_profile(settings, model_manager, hardware_info)`**:
       ```python
       def resolve_profile(
           settings: SettingsStore,
           model_manager: ModelManager,
           hardware_info: HardwareInfo,
       ) -> ProfileResolutionResult:
       ```

       Logic (per D-01, D-02, D-03, D-04):
       a. `preferred_profile_name = settings.model_profile` (e.g., "cpu-portable")
       b. Try to get the profile from `model_manager.get_profile(preferred_profile_name)`. If unknown → treat as "cpu-portable" (shipping default) and log warning.
       c. Retrieve the profile's `preferred_model` and `fallback_order`.
       d. Build ordered list: `[preferred_model] + fallback_order`.
       e. For each model_name in ordered list:
          - Get ModelInfo via `model_manager.get_model(model_name)`
          - If `model_manager.validate_model(info)` returns True → this is the selected model
       f. If a model is found:
          - `fallback_applied = (found_model_name != preferred_model)`
          - `profile_used = preferred_profile_name` (NOT the fallback profile name — we stayed within the user's preferred profile's fallback chain)
          - If `preferred_profile_name == "nvidia-dev"` and `hardware_info.has_nvidia_gpu is False` and a model was found → `advisory_message = "NVIDIA profile selected but no NVIDIA GPU detected. Using CPU model."`
          - If `preferred_profile_name == "nvidia-dev"` and `hardware_info.has_nvidia_gpu is True` and fallback was applied → `advisory_message = "NVIDIA GPU detected but faster-whisper dependencies or model missing. Using CPU fallback. See setup guide."`
          - Return `ProfileResolutionResult(model_info=info, profile_used=..., fallback_applied=..., advisory_message=...)`
       g. If NO model found after exhausting fallback_order:
          - `error_message = model_manager.get_missing_model_error(preferred_model)` (or concatenated guidance)
          - Return `ProfileResolutionResult(model_info=None, profile_used=preferred_profile_name, fallback_applied=False, error_message=error_message)`

    3. **Critical constraints**:
       - NEVER call `settings.model_profile = ...` — the user's preference is read-only here (D-03)
       - Never download anything
       - Never raise exceptions — always return `ProfileResolutionResult`
       - `nvidia-dev` falling back to CPU models is expected and handled gracefully (D-11)
