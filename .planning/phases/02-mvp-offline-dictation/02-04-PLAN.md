Implement `src/paste_controller.py`:

Enum `PasteMode`:
- `SENDINPUT` — primary: simulate Ctrl+V keystrokes via SendInput
- `CLIPBOARD_ONLY` — fallback: set clipboard, user manually pastes

Class `PasteController`:
- `__init__(self, mode: PasteMode = PasteMode.SENDINPUT)`
- `paste(self, text: str) -> bool` — paste text using current mode, return success
- `_paste_sendinput(self, text: str) -> bool` — internal SendInput implementation
- `_paste_clipboard(self, text: str) -> bool` — internal clipboard-only implementation
- `_backup_clipboard() -> tuple[int, Any]` — save current clipboard format and data
- `_restore_clipboard(format: int, data: Any) -> bool` — restore previous clipboard content

SendInput implementation (ctypes, no pywin32 required for keystrokes):
```python
import ctypes
from ctypes import wintypes

user32 = ctypes.windll.user32

INPUT_KEYBOARD = 1
KEYEVENTF_KEYUP = 0x0002
VK_CONTROL = 0x11
VK_V = 0x56

class KEYBDINPUT(ctypes.Structure):
    _fields_ = [("wVk", wintypes.WORD), ("wScan", wintypes.WORD), ("dwFlags", wintypes.DWORD),
                ("time", wintypes.DWORD), ("dwExtraInfo", wintypes.ULONG_PTR)]

class INPUT(ctypes.Structure):
    _fields_ = [("type", wintypes.DWORD), ("ki", KEYBDINPUT)]
```

Paste sequence:
1. Backup current clipboard
2. Set clipboard to new text (CF_UNICODETEXT)
3. If mode == SENDINPUT: simulate Ctrl+V (Ctrl down, V down, V up, Ctrl up) with 10ms sleep between events
4. Wait 50ms for paste to complete
5. Restore previous clipboard content
6. Return True if all steps succeeded

Clipboard implementation:
- Use `win32clipboard` (pywin32) OR pure ctypes `OpenClipboard`, `EmptyClipboard`, `SetClipboardData`, `CloseClipboard`
- Recommend pywin32 for simplicity: `win32clipboard.OpenClipboard()`, `win32clipboard.EmptyClipboard()`, `win32clipboard.SetClipboardText(text)`, `win32clipboard.CloseClipboard()`
- For backup: `win32clipboard.GetClipboardData(format)` where format is `win32con.CF_UNICODETEXT` or `win32con.CF_TEXT`
- Handle cases where clipboard is empty or contains non-text data

Error handling:
- If SendInput fails (returns 0), automatically fall back to CLIPBOARD_ONLY mode for this paste
- If clipboard is locked by another app, retry once after 100ms, then fail gracefully
- Never raise unhandled exceptions to the caller; log error via Diagnostics and return False

`tests/test_paste_controller.py`:
- Mock `win32clipboard` and `ctypes.windll.user32.SendInput` to test logic without Windows API
- Test backup/restore round-trip
- Test SendInput key sequence order (Ctrl down, V down, V up, Ctrl up)
- Test fallback to CLIPBOARD_ONLY when SendInput returns 0
- Test empty text handling
- Test clipboard locked error handling
