  <files>src/privacy_guard.py, tests/test_privacy_guard.py</files>

Implement `src/privacy_guard.py`:

Exception `NetworkBlockedError(Exception)`:
- Raised when any code attempts a network call after enforcement is active

Class `PrivacyGuard`:
- `__init__(self, diagnostics: Diagnostics)`
- `enforce(self) -> None` — activate blocking; can only be called once
- `is_enforced(self) -> bool` — check if active

Blocking implementation:
1. **socket.socket monkey-patch:**
   ```python
   import socket
   _original_socket = socket.socket
   def _blocked_socket(*args, **kwargs):
       raise NetworkBlockedError("Network calls are blocked by privacy policy")
   socket.socket = _blocked_socket
   ```

2. **urllib.request block:**
   ```python
   import urllib.request
   urllib.request.urlopen = lambda *a, **kw: raise NetworkBlockedError(...)
   ```

3. **ssl module block (defense in depth):**
   ```python
   import ssl
   ssl.wrap_socket = lambda *a, **kw: raise NetworkBlockedError(...)
   ```

4. **QtNetwork prevention:**
   - Set environment variable `QT_NO_NETWORK` or ensure QtNetwork module is never imported
   - If PySide6.QtNetwork is already imported, monkey-patch `QNetworkAccessManager` methods

5. **Validate at startup:**
   - After enforcing, attempt a test connection to `127.0.0.1:1` (closed port)
   - Expect `NetworkBlockedError`, not `ConnectionRefusedError`
   - Log success/failure via Diagnostics

`tests/test_privacy_guard.py`:
- Test enforce() blocks socket.socket()
- Test enforce() blocks urllib.request.urlopen()
- Test enforce() is idempotent (second call does nothing)
- Test NetworkBlockedError raised with correct message
- Test QtNetwork patch if PySide6.QtNetwork is available

Implement `src/dictation_loop.py`:

Enum `DictationState`:
- `IDLE`
- `LISTENING` — audio capture active
- `PROCESSING` — transcription in progress
- `READY` — text pasted, waiting for next utterance
- `ERROR` — unrecoverable error occurred

Class `DictationLoop(QObject)`:
- Signals:
  - `state_changed(state: DictationState, message: str = "")`
  - `text_pasted(text: str)` — emitted after successful paste (text may be redacted/omitted for privacy)
  - `error_occurred(error: str)` — human-readable error message

- `__init__(self, settings: SettingsStore, audio_capture: AudioCapture, speech_detector: SpeechDetector, transcriber: Transcriber, paste_controller: PasteController, diagnostics: Diagnostics)`
- `start(self) -> None` — begin dictation session
  1. Set state LISTENING
  2. Start AudioCapture with callback that feeds SpeechDetector
  3. On SPEECH_START: begin accumulating audio buffer
  4. On SPEECH_END: stop capture, set state PROCESSING, send buffer to Transcriber
  5. On transcription result: paste text, set state READY, auto-reset to IDLE after 2s
- `stop(self) -> None` — cancel current session, return to IDLE
- `toggle(self) -> None` — if IDLE → start(); if LISTENING/PROCESSING → stop()

Error handling:
- Missing model: state ERROR, message "Model not found. See side-load instructions."
- No microphone: state ERROR, message "No microphone detected."
- Transcription failed: state ERROR, message "Transcription failed. Try again."
- Paste failed: state ERROR, message "Could not paste. Clipboard may be locked."
- All errors logged via Diagnostics (redacted)

Audio buffer management:
- Accumulate int16 frames in `list[np.ndarray]` during speech
- On SPEECH_END, concatenate into single array: `np.concatenate(frames)`
- Pass concatenated array to transcriber
- Clear buffer after transcription (even on error)
- No audio persists to disk

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → Hotkey | Local keyboard input, trusted |
| DictationLoop → PasteController | Transcribed text crosses to system clipboard/target app |
| PrivacyGuard → Network Stack | All network APIs blocked before app logic runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-14 | Information Disclosure | dictation_loop.py | mitigate | Audio buffers cleared after transcription. Transcript passed directly to paste, not logged. |
| T-02-15 | Denial of Service | shell_integration.py | mitigate | UnregisterHotKey on exit. Process message filter removed on cleanup. |
| T-02-16 | Elevation of Privilege | privacy_guard.py | accept | Blocks user-mode network APIs. Cannot prevent kernel-level networking or external processes. |
| T-02-17 | Repudiation | diagnostics.py | mitigate | Redacted event log provides audit trail without PII. Log file permissions: user-only read/write. |
| T-02-18 | Spoofing | paste_controller.py | mitigate | SendInput targets foreground window only; cannot inject into arbitrary processes. |
</threat_model>
