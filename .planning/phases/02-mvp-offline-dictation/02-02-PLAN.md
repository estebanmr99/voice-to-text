<task type="auto">
  <name>Task 2: Implement SpeechDetector with WebRTC VAD</name>
  <files>src/speech_detector.py, tests/test_speech_detector.py</files>
  <action>
Implement `src/speech_detector.py`:

Enum `VADEvent`:
- `SPEECH_START`
- `SPEECH_END`
- `SILENCE`

Class `SpeechDetector`:
- `__init__(self, aggressiveness: int = 1, frame_duration_ms: int = 30, samplerate: int = 16000)`
- `process_frame(self, frame: np.ndarray) -> VADEvent | None` — returns event on state transitions
- `is_speech(self, frame: np.ndarray) -> bool` — raw VAD decision
- `reset(self)` — clear internal state

Implementation details:
- Use `webrtcvad.Vad(aggressiveness)` where aggressiveness is 0-3
- WebRTC VAD requires 16-bit mono PCM at 8kHz, 16kHz, or 32kHz with 10ms, 20ms, or 30ms frames
- Convert numpy int16 array to bytes: `frame.tobytes()`
- State machine:
  - Track consecutive speech frames (threshold: 3 frames = 90ms to declare SPEECH_START)
  - Track consecutive silence frames (threshold: 10 frames = 300ms to declare SPEECH_END)
  - While in speech, accumulate audio buffer
  - When SPEECH_END triggered, return accumulated buffer via callback or property

`tests/test_speech_detector.py`:
- Test with synthetic audio: zeros (silence) and sine wave (simulated speech)
- Note: webrtcvad may classify sine wave as speech; test the state machine logic primarily
- Test aggressiveness levels 0-3
- Test frame duration validation (10, 20, 30 ms only)
- Test reset() clears state
- Mock webrtcvad.Vad if needed to test state machine independently
