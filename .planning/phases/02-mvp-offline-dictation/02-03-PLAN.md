Implement `src/transcriber_worker.py`:

This module runs INSIDE the worker process (separate Python interpreter).

Function `run_worker(audio_queue: multiprocessing.Queue, result_queue: multiprocessing.Queue, cancel_event: multiprocessing.Event, model_path: str, n_threads: int = 4)`:
1. Load model: `from pywhispercpp.model import Model; model = Model(model_path, n_threads=n_threads)`
2. Loop until cancel_event is set:
   a. Read audio bytes or numpy array from audio_queue (blocking with timeout)
   b. If audio data received, transcribe: `segments = model.transcribe(audio_path_or_array)`
   c. Join segment texts: `text = " ".join(s.text for s in segments).strip()`
   d. Put result dict on result_queue: `{"text": text, "error": None}`
   e. If exception occurs, put `{"text": "", "error": str(e)}`
3. On cancel or queue close, exit cleanly

Audio format:
- Worker accepts raw audio as numpy int16 array or WAV file path
- For memory efficiency, pass numpy array via queue (multiprocessing can pickle numpy arrays)
- Alternative: save temporary WAV and pass path (simpler but creates temp files)
- **Decision for MVP:** Pass numpy array directly; no temp files to avoid retention risk

Implement `src/transcriber.py`:

Class `Transcriber`:
- `__init__(self, model_manager: ModelManager)`
- `start(self, model_info: ModelInfo) -> bool` — spawn worker process, return success
- `stop(self) -> None` — set cancel_event, join process with 5s timeout, terminate if needed
- `transcribe(self, audio: np.ndarray) -> str` — send audio to worker, block for result, return text or raise TranscriptionError
- `is_running(self) -> bool` — check worker process is alive
- `get_last_error(self) -> str | None` — retrieve last error from worker

Worker lifecycle:
- Process spawned on first transcription or explicit start()
- Process kept alive between transcriptions for efficiency
- Process terminated on app exit or model switch
- Use `multiprocessing.Process(target=run_worker, args=(...))`

Error handling:
- If model fails to load: raise `TranscriptionError` with message from worker
- If worker crashes: restart on next transcription attempt (with backoff)
- If audio is empty or too short: return empty string without calling model
