## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| ctypes.wintypes.ULONG_PTR missing | On some Python builds, `ctypes.wintypes.ULONG_PTR` does not exist. Causes ImportError on paste_controller.py load. | advisory | Define ULONG_PTR manually: `ctypes.c_ulonglong if sizeof(void*) == 8 else ctypes.c_ulong` |
| webrtcvad requires VC++ Build Tools | `webrtcvad-wheels` fails to build on Windows without Microsoft Visual C++ 14.0+. Blocks pip install. | advisory | Made webrtcvad optional with fallback energy-based VAD. Install VC++ Build Tools (~6GB) for production accuracy. |
| Python not on PATH in VS Code Insiders | VS Code Insiders terminal may not inherit the same PATH as Warp/other terminals. `python`/`py` commands fail. | advisory | Use `.venv\Scripts\python.exe` directly or fix terminal profile in VS Code settings. |
| SendInput ctypes array type | `ctypes.cast()` rejects Python tuples for INPUT arrays. Must use `(INPUT * N)(...)` ctypes array. | advisory | Always create ctypes arrays with `(TYPE * count)(...)` syntax, never tuples. |
| Qt enum values differ by version | Hard-coding hex values for Qt.WindowStaysOnTopHint (0x8000) fails on PySide6 6.8.0 where the value is 0x40000. | advisory | Always use `Qt.WindowStaysOnTopHint` enum reference, never hard-coded hex literals. |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.

- **VAD backend is injectable** — `SpeechDetector.__init__` accepts `vad_backend` parameter for testability and future VAD backends (Silero).
- **No pytest-qt dependency** — Manual QApplication fixture in conftest.py to minimize dev dependencies.
- **Programmatic tray icon fallback** — No bundled PNG assets; draws icon with QPainter.
- **Settings file in user home** — `~/.spanglish-dictation/settings.json` and `~/.spanglish-dictation/logs/`.
- **Model assets not in git** — Registry JSON stores expected paths; missing models return local error with side-load guidance (no network download).
