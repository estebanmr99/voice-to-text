    **2. Create `src/glossary.py`** — GlossaryStore and GlossaryEntry data classes:

    ```python
    @dataclass
    class GlossaryEntry:
        input: str       # lowercase matching key (what Whisper produces)
        output: str       # correct rendering
        context: str = "" # optional note, not used in matching

    class GlossaryStore:
        def __init__(self, default_path: Path, user_path: Path | None = None):
            """Load default glossary and optionally merge user glossary on top."""

        def load(self) -> list[GlossaryEntry]:
            """Return merged entries: defaults + user overrides."""

        def validate(self, entries: list[dict]) -> list[str]:
            """Validate a list of entry dicts, returning list of error strings.
            Empty list = valid."""

        @staticmethod
        def from_settings(settings: SettingsStore) -> "GlossaryStore":
            """Factory: create GlossaryStore from settings.glossary_path."""
    ```

    Key behaviors:
    - `load()` reads default glossary first, then user glossary if it exists
    - User entries override defaults when `input` keys collide
    - Missing user glossary file is NOT an error — returns defaults only
    - Invalid JSON in user glossary logs a warning and falls back to defaults only
    - `validate()` checks: each entry has "input" (str, non-empty) and "output" (str) keys
    - `validate()` returns empty list on success, list of error strings on failure

    **3. Create `src/post_processor.py`** — PostProcessor class:

    ```python
    class PostProcessor:
        def __init__(self, glossary_store: GlossaryStore):
            """Initialize with a glossary store. Load entries eagerly."""

        def normalize(self, text: str) -> str:
            """Apply glossary entries to text. Word-boundary-aware replacement.
            Returns the normalized text."""

        def preview(self, text: str) -> str:
            """Same as normalize() — alias for confirmation mode clarity."""

        def get_applied_rules(self, text: str) -> list[str]:
            """Return list of input terms that matched, for diagnostics.
            Does NOT log raw transcript text."""
    ```

    Key behaviors for `normalize()`:
    - Iterate glossary entries in order (defaults first, user overrides second)
    - For each entry: match `input` as a WHOLE WORD only using `\b{input}\b` regex
    - Apply regex replacement: `re.compile(rf'\b{re.escape(entry.input)}\b', re.IGNORECASE)`
    - Single pass: each word position is matched at most once, in entry order
    - Preserve surrounding punctuation, whitespace, and accented characters exactly
    - Return the result string
    - Empty string input returns empty string
    - Text with no matches returns original text unchanged
