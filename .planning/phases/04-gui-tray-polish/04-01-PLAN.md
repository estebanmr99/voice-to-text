  <files>src/settings_dialog.py</files>
  <action>
Create `src/settings_dialog.py` with a `SettingsDialog(QDialog)` class.

Layout: Use a `QFormLayout` inside a `QVBoxLayout` for clean alignment, or grouped sections with `QGroupBox`. The dialog should be resizable and have a minimum width of 480px.

Fields to expose (map directly to SettingsStore properties):
1. **Hotkeys group:**
   - `hotkey_push_to_talk`: `QLineEdit` with placeholder "Ctrl+Alt+D"
   - `hotkey_toggle`: `QLineEdit` with placeholder "Ctrl+Alt+T"
   - Add a small QLabel note: "Format: Ctrl+Alt+Key or Win+Key"

2. **Audio group:**
   - `audio_device_index`: `QComboBox` populated from `AudioCapture.list_devices()`. Show device name; store index as data. Include "Default" option with `None` data.

3. **Processing group:**
   - `model_profile`: `QComboBox` populated from `model_manager.list_profiles()` (if model_manager provided). Show `display_name`; store `canonical_name` as data.
   - `vad_profile`: `QComboBox` with options "webrtc" (WebRTC VAD -- default) and "silero" (Silero VAD -- accurate). Store canonical string.

4. **Paste & Language group:**
   - `paste_mode`: `QComboBox` with "immediate" and "confirmation". Show user-friendly labels "Paste immediately" and "Confirm before paste".
   - `language`: `QComboBox` with "auto", "es", "en". Labels: "Auto-detect", "Spanish", "English".

5. **Glossary group:**
   - `glossary_path`: `QLineEdit` with a `QPushButton` "Browse..." that opens `QFileDialog.getOpenFileName` filtering for `*.json *.yaml *.yml *.txt`. Show full path or empty string.

Buttons: `QDialogButtonBox` with Save and Cancel. Save validates inputs, writes to SettingsStore, calls `settings.save()`, and accepts the dialog. Cancel rejects without saving.

Validation:
- Hotkey format: must match pattern like "Ctrl+Alt+D" or "Win+Shift+F". Accept Mod+Key or Mod+Mod+Key where Mod is Ctrl/Alt/Shift/Win and Key is a single letter/digit/F-key. Use simple regex: `^(Ctrl|Alt|Shift|Win)(\+(Ctrl|Alt|Shift|Win))*\+[A-Z0-9]$` (case-insensitive). Invalid hotkeys show `QMessageBox.warning` and block save.
- Audio device: if `sounddevice` unavailable, disable the combo and show "sounddevice not available".

Constructor signature:
```python
def __init__(
    self,
    settings: SettingsStore,
    audio_capture: AudioCapture | None = None,
    model_manager: ModelManager | None = None,
    parent: QWidget | None = None,
) -> None:
```

Read current values from `settings` on dialog open. On save, write back to `settings` properties (which auto-persist via `settings.save()`).

Add module-level docstring explaining the dialog is offline-only and does not network.
