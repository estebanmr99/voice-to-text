## Current codebase state

### DictationLoop (`src/dictation_loop.py`)
State machine: IDLE -> LISTENING -> PROCESSING -> READY/ERROR -> IDLE.

In `_on_speech_end()`:
1. Concatenates audio buffer
2. Calls `transcriber.transcribe(audio)`
3. Calls `paste_controller.paste(text)`
4. Emits `text_pasted` signal
5. Auto-resets to IDLE after 2s

The method ALWAYS pastes. There is no branch for confirmation mode.

### SettingsStore (`src/settings_store.py`)
`paste_mode` property returns "immediate" or "confirmation".

### PasteController (`src/paste_controller.py`)
`paste(text)` uses SendInput Ctrl+V by default, falls back to clipboard-only. No confirmation logic.

### ShellIntegration (`src/shell_integration.py`)
Tray has Paste Mode submenu with Immediate/Confirmation radio buttons. Selection updates `settings.paste_mode`.

### main.py (`src/main.py`)
Wires `dictation_loop.state_changed` to `shell.show_status_panel()`.
Wires `shell.hotkey_pressed` to `dictation_loop.toggle()`.
No confirmation flow wiring exists.

### Existing tests (`tests/test_dictation_loop.py`)

3. Add public methods:
```python
def confirm_paste(self, text: str) -> None:
    """Paste the given text (possibly edited) and transition to READY."""
    try:
        ok = self._paste_controller.paste(text)
    except Exception as exc:
        logger.exception("Paste failed: %s", exc)
        self._handle_error("paste", "Could not paste. Clipboard may be locked.")
        return

    if not ok:
        self._handle_error("paste", "Could not paste. Clipboard may be locked.")
        return

    self._set_state(DictationState.READY, "Dictation complete")
    self.text_pasted.emit(text)
    self._schedule_reset(delay_ms=2000)

def cancel_paste(self) -> None:
    """Discard the current transcription and return to IDLE."""
    self._set_state(DictationState.IDLE)
```

4. Ensure `_schedule_reset` is NOT called in the confirmation branch (the dialog owns the next state transition).
