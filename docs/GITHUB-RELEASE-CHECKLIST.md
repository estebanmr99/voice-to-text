# GitHub Release Checklist

Pre-publish verification steps for a Spanglish Dictation release on GitHub.

## Pre-tag checks

- [ ] All tests pass: `python -m pytest tests -q`
- [ ] Full local release pipeline passes: `powershell -ExecutionPolicy Bypass -File scripts/prepare_release.ps1 -Version 0.1.0`
- [ ] Licence bundle check passes: `python scripts/generate_license_bundle.py --check`
- [ ] Offline smoke test passes: `powershell -ExecutionPolicy Bypass -File scripts/smoke_offline.ps1`
- [ ] No model binaries, CUDA/cuDNN DLLs, or .gguf files in the working tree
- [ ] `models/` is in `.gitignore`
- [ ] `dist/` is in `.gitignore`
- [ ] `README.md` references the correct version
- [ ] `README.md` links to `docs/INSTALL.md`, `docs/RELEASE.md`, and the real GitHub Releases page

## Release artifacts

Each release produces and publishes:

| Artifact | Source | Required |
|----------|--------|----------|
| `spanglish-dictation-portable-{version}.zip` | `scripts/build_portable.ps1` | Yes |
| `sbom.cdx.json` | `cyclonedx_py` via `scripts/prepare_release.ps1` | Yes |
| `SHA256SUMS.txt` | `scripts/prepare_release.ps1` | Yes |
| `LICENSES/THIRD-PARTY-NOTICES.md` | `scripts/generate_license_bundle.py` | Yes |
| `LICENSES/MODEL-NOTICES.md` | `scripts/generate_license_bundle.py` | Yes |
| `docs/RELEASE.md` | Static documentation | Yes |

## Blocked artifacts (must NOT appear in release assets)

- [ ] No model binaries: no `*.bin`, `*.gguf` files in release zip
- [ ] No GPU redistribution DLLs: no `cudnn*.dll`, `cublas*.dll`, `cudart*.dll`
- [ ] No `models/` directory in release zip
- [ ] No NVIDIA redistributable files
- [ ] **No bundled models** — users side-load models from documented URLs

## SBOM publication

- [ ] CycloneDX SBOM (`sbom.cdx.json`) covers all runtime dependencies from `requirements.txt`
- [ ] SBOM generated for the exact release version
- [ ] SBOM published as a GitHub release asset

## Model side-loading verification

- [ ] `docs/MODEL-SIDELOADING.md` has correct SHA-256 hashes for both models
- [ ] Model source URL points to `huggingface.co/ggerganov/whisper.cpp`
- [ ] Download instructions use curl (user-side), not runtime app downloads
- [ ] A side-loaded model works after extracting the portable zip on a clean Windows machine

## Post-tag automated steps

Triggered by pushing a `v*` tag:

1. GitHub Actions runner checks out the repository
2. Installs Python 3.12 and all dependencies
3. Runs `scripts/prepare_release.ps1` (tests, licence, SBOM, build, checksums, verify)
4. Runs `scripts/smoke_offline.ps1` for privacy/offline regression
5. Publishes all release artifacts via `softprops/action-gh-release`

The workflow never downloads models, never references CUDA/cuDNN, and never
installs `huggingface-cli`.

GitHub Actions exists only to automate GitHub publishing after a `v*` tag. It is not part of runtime app behavior and does not weaken the app's no-runtime-network guarantee.

## Before publishing

- [ ] Review release notes generated by GitHub
- [ ] Verify all 6 artifacts are attached to the release
- [ ] Confirm SHA-256 checksums match local build
- [ ] Verify the portable zip runs without admin rights on a clean Windows machine
- [ ] Confirm offline smoke test passes on the published artifacts
- [ ] Confirm the public release page is `https://github.com/estebanmr99/voice-to-text/releases`
