# Windows Offline Spanglish Dictation v0.1.0

First public release of Windows Offline Spanglish Dictation: a Windows-first desktop app that captures technical Spanglish speech, transcribes it locally, and pastes the result into your active app without cloud services.

## Highlights

- Push-to-talk and toggle-mode dictation from the Windows tray
- Local whisper.cpp transcription with deterministic Spanglish normalization
- Confirmation-before-paste mode for editing before insertion
- Windows user-mode portable build with no admin requirement

## Offline and privacy guarantees

- Fully offline at runtime — no cloud ASR, no runtime network access, no account required
- No telemetry — no analytics, crash uploads, or usage metrics
- No retained audio or transcripts by default
- Models are not bundled and are never downloaded by the app at runtime

## Included release assets

- `spanglish-dictation-portable-0.1.0.zip` — portable Windows build
- `sbom.cdx.json` — CycloneDX dependency SBOM for this release
- `SHA256SUMS.txt` — integrity hashes for the published release assets

## Before first launch

You must side-load at least one supported Whisper model before dictation will work. The release intentionally does **not** bundle models, `models/`, CUDA DLLs, or cuDNN DLLs.

- Install/extract steps: `docs/INSTALL.md`
- Privacy details: `docs/PRIVACY.md`
- Model setup and checksums: `docs/MODEL-SIDELOADING.md`

After downloading the portable zip from GitHub Releases, extract it to a normal user-writable folder, side-load a supported model into `models/`, and launch `spanglish-dictation.exe`.

## Notes for this public ship

- This release is for side-loaded offline use on Windows
- NVIDIA/CUDA acceleration remains a development-path option and is not redistributed here
- GitHub publication is only for distribution; the shipped app itself remains fully offline at runtime
