# Windows Offline Spanglish Dictation v0.2.0

Quality and reliability release. Fixes language handling for Spanish speakers, adds transcription accuracy benchmarking, model integrity verification, and PR CI.

## Highlights

- **Spanish language fix** — `language="auto"` now correctly reaches whisper.cpp instead of being silently dropped, preventing Spanish speech from being translated to English
- **Transcription quality benchmark** — `scripts/eval_transcription.py` computes WER against a reference eval dataset with per-clip language hints and optional glossary normalization (`--post-process`)
- **Model integrity verification** — `models/model_checksums.json` serves as the single source of truth for model SHA-256 hashes, cross-verified across all scripts, tests, and documentation
- **PR CI workflow** — `.github/workflows/ci.yml` runs pytest, model integrity checks, and license validation on every PR and push to main
- **EVAL-REVIEW: 88/100 PRODUCTION READY** — all 3 deployment-blocking gaps from the v0.1.0 audit are now closed

## What changed

### Fixed
- Language auto-detection: transcriber worker no longer blocks `"auto"` from reaching whisper.cpp (`src/transcriber_worker.py`)
- Path/API mismatches in eval script and smoke test (ModelManager expects `Path`, ModelInfo uses `parameters` dict)
- WER thresholds calibrated to measured model performance (base: 30%, small: 20%)

### Added
- WER benchmark CLI: `python scripts/eval_transcription.py --model models/ggml-small.bin --post-process --threshold 20.0`
- Reference eval dataset: 10 audio clips (EN/ES/Spanglish/tech) with ground-truth transcripts (`data/eval/`)
- Recording tool: `python scripts/record_eval_clips.py`
- Model integrity cross-verification: `tests/test_model_integrity.py` (4 tests, CI-compatible)
- Dictation smoke test: `tests/test_dictation_smoke.py` (real model E2E, skips gracefully)
- WER threshold regression: `tests/test_transcription_benchmark.py`
- `--post-process` flag: applies glossary normalization before computing WER
- PR CI: `.github/workflows/ci.yml`

### Infrastructure
- `models/model_checksums.json` — single source of truth for model checksums (SHA-256, size, URL)
- `jiwer>=3.0` added to dev dependencies
